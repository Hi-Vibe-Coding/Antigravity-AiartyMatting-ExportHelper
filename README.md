# AiartyMatting 导出助手 (Antigravity-AiartyMatting-ExportHelper)

基于 **PySide6** 与 **Fluent Design (`PyQt-Fluent-Widgets`)** 打造的 Windows 本地高效图片识别与重命名处理工具。

---

## 功能特性

### 1. 现代流畅 UI
- **Windows 11 Fluent 风格**：圆角卡片、平滑滚动、深色/浅色自适应主题。
- **屏幕空间自适应**：自动根据当前屏幕分辨率（约 82% 视口）适配居中展现。
- **纵向双模块滚动流**：区域 1 优先铺满首屏，支持使用右侧滚动条向下滑动快速浏览模块 2。

### 2. 模块 1（特殊命名图片识别与逻辑重命名）
- **子文件夹拖拽支持**：
  - 左侧仅支持拖入子文件夹（自动过滤普通文件）。
  - 支持逐一拖入并自动去重校验。
  - 每个文件夹以小图标卡片呈现，支持单项移除或一键清空。
- **动态扫描交互**：
  - 添加子文件夹后，右下角即时浮现「开始扫描」按钮。
  - **支持「递归扫描深层子目录」复选框（默认勾选）**：开启后自动深度穿透并扫描子文件夹内的所有嵌套子目录中的图片，关闭则仅扫描直属第 1 层。
  - 异步后台扫描（`QThreadPool`），扫描过程中界面不卡顿。
- **完整图片扫描与状态区分**：
  - 完整扫描并列出子文件夹内的所有图片文件（.png / .jpg / .jpeg / .webp）。
  - **精准向上推算「所在子文件夹」层级路径**：如直接在根目录下为 `Batch_Export_案例3`，嵌套在内部为 `Batch_Export_案例3\新建文件夹`，层次分明准确。
  - **支持「只显示有效」复选框（默认不勾选）**：位于结果列表标题旁，勾选后列表瞬时过滤刷新，仅展示处理状态为 `待重命名` 的有效图片。
  - 在「处理状态」列明确标识：
    - **`待重命名`**：符合特殊命名规则（如 `B0-001__1_attr1_subject.png`），自动推导逻辑父名 `B0-001` 与目标名 `B0-001__1.png`；
    - **`无效`**：不符合特殊命名机制或格式非 `.png` 的图片，逻辑名与目标名显示 `-`，鼠标悬停可查看无效原因。
  - **重名冲突自动熔断保护**：
    - 扫描完成后，若检测到列表中有**不止 1 条数据指向相同的「目标重命名」文件**，「一键应用重命名」按钮**自动强制变灰禁用**，并对重名项予以警告提示，彻底杜绝文件相互覆盖风险。

### 3. 模块衔接与模块 2 交互
- **醒目的行动过渡栏**：
  - 位于模块 1 与模块 2 之间，放置了高规格的主操作按钮「**准备复制到[逻辑父文件夹]**」。
- **模块 2 半透明锁定机制**：
  - 初始状态下，整个模块 2 区域被一层现代毛玻璃质感的**半透明遮罩**覆盖，并提示处于待命锁定状态；
  - 点击「准备复制到[逻辑父文件夹]」后：
    - 若列表中**没有「待重命名」有效图片**：弹出友好提醒 *“抱歉，没有有效图片可以转移。”*，模块 2 保持锁定；
    - 若列表中**存在「待重命名」有效图片**：自动淡出半透明遮罩，完全解锁模块 2 交互，并平滑下滚展现。

## 快速启动

### 运行环境
- Windows 10 / 11
- Python 3.10+

### 一键运行
直接双击项目根目录下的 [`run.bat`](run.bat) 即可。

### 命令行运行
```bash
# 激活虚拟环境
.\.venv\Scripts\activate

# 运行主程序
python main.py
```
