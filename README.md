# Aiarty Image 导出助手 (Aiarty-Image-ExportHelper)

基于 **PySide6 (Qt6)** 与 **Fluent Design (`PyQt-Fluent-Widgets`)** 打造的 Windows 本地高效图片识别、命名验证、逻辑溯源与批量分发工具。  
支持 **Aiarty Image Matting（抠图）** 与 **Aiarty Image Enhancer（画质增强）** 两大工作流。

---

## 🌟 核心设计与功能特性

### 1. 现代 Fluent UI 与多模块分段导航
- **分段胶囊选项卡驱动**：顶部配备 `SegmentedWidget` 分段胶囊导航，一键切换两大核心处理模块：
  - **Aiarty Image Matting（抠图）**
  - **Aiarty Image Enhancer（画质增强）**
- **状态安全重置隔离**：在两大核心模块之间切换时，原始模块与目标模块均自动恢复初始干净状态，避免不同业务线数据混淆。
- **自适应高分屏布局**：根据当前屏幕分辨率自动适配视口（约 82% 视口居中），左右比例支持 Splitter 拖拽调节，纵向支持平滑滚动（`SmoothScrollArea`）。
- **深浅主题自适应**：跟随 Windows 系统深色/浅色偏好自动切换，调色板与各级控件保持高对比度与清晰度。

### 2. 工作流 A：Aiarty Image Matting（抠图）

包含 **模块 1（图片识别与重命名）** ➜ **过渡衔接栏** ➜ **模块 2（逻辑父目录溯源与分发复制）**：

#### 模块 1：特殊命名图片识别与重命名
- **子文件夹拖入与右键粘贴管理**：
  - 支持逐一拖入子文件夹并自动去重校验；
  - **支持剪贴板粘贴（等效于拖拽）**：在拖入区域内**右键点击**，弹出菜单选择【**粘贴文件夹**】，即可批量读取剪贴板中的文件夹（支持 Windows 资源管理器直接 `Ctrl+C` 文件夹或地址栏路径文本）；
  - 常态显示「递归扫描深层子目录」复选框（默认勾选）。
- **图片命名规则**：
  $$\text{[逻辑父文件夹名]}\_\_\text{[序号]}\_attr1\_subject\text{.png}$$
  - **逻辑父名**：`[字母+纯数字]-[纯数字]`（例如 `B0-001`、`ABc00-101`）。
  - **双下划线**：必须通过连续 2 个下划线 `'__'` 分隔。
  - **纯数字序号**：紧随 `'__'` 后的纯数字组合。
  - **固定后缀**：`_attr1_subject.png`。
- **6 列详细表格**：`序号`、`所在子文件夹`、`原文件名`、`逻辑父文件夹名`、`目标重命名`、`处理状态`。
- **重名冲突自动熔断**：若列表中存在多项指向同一目标名称，一键重命名按钮自动禁用，状态栏触发大红色流动跑马灯循环警示。
- **规则示例视觉弹窗**：点击右上角【规则示例】按钮，弹出色彩解构胶囊与正反示例对照面板。

#### 衔接过渡区
- 居中配备主操作按钮【**准备复制到[逻辑父文件夹]**】。
- 校验若列表中无有效待重命名图片，飘字提醒；若存在有效图片，则注入数据源并平滑解锁模块 2。

#### 模块 2：溯源到父文件夹与文件复制
- **初始半透明遮罩锁定**：未在模块 1 确认前保持锁定，防止误操作。
- **源文件夹拖拽与右键粘贴分析**：左侧拖入目标母目录（亦可直接在区域内**右键点击**选择【**粘贴文件夹**】），右下角点击【开始分析】，自动在源目录下递归寻找与“逻辑父文件夹名”同名的目标文件夹。
- **5 列详细对照数据表**：`序号`、`原文件`（纯文件名）、`预期重命名`、`状态`、`跳转`。
- **智能「跳转」与文件定位**：
  - 每行配备带文件夹图标的「**跳转**」按钮；
  - 点击后直接调用 Windows 资源管理器打开溯源文件夹，并**自动高亮选中目标图片文件**；
  - 若目标图片尚未物理生成，则安全降级为直接打开目标逻辑父文件夹，避免系统误开“我的文档”；若未匹配到有效目录则自动置灰禁用。
- **「先删除同名图片文件」选项（默认不勾选）**：
  - 位于对照数据表表头，开启后在复制新图片写入前，优先清理目标同名文件夹中该主名称的所有格式旧图片（覆盖 `.png`、`.jpg`、`.jpeg`、`.webp`）；
  - **动态警示状态**：勾选后状态列即时联动更新（如 `即将被写入到[A 预制\Bracelet\B0-001]，原文件夹的B0-001_1.xxx会被删除`），取消勾选则恢复覆盖警示，统计数据实时重算；
  - **物理安全删除**：在后台复制工作线程中精准物理删除对应同名旧格式图片，并保留其它非同名文件完整无损。
- **异步文件复制与进度反馈**：点击右下角【开始复制】，后台逐一复制图片到对应目录，实时更新进度条与百分比；复制完成后按钮自动置灰锁定为「已全部复制」并飘字提醒。

### 3. 工作流 B：Aiarty Image Enhancer（画质增强）

专为画质增强导出文件定制的自动化识别与分发流程：

#### 模块 1：画质增强图片识别
- **子文件夹拖入与递归扫描**：同样支持子文件夹管理与深层递归扫描。
- **筛选匹配规则**：
  $$\text{[逻辑父文件夹名]}\_\_\text{[纯数字序号]}\text{.png}$$
  - 扩展名必须为 `.png`（不区分大小写）；
  - 序号必须紧接纯数字组合（如 `1`、`0123`）；
  - 必须通过连续双下划线 `'__'` 分隔；
  - 逻辑父文件夹名必须满足：`[字母+纯数字]-[纯数字]`（如 `B0-001`、`ABc00-101`；字母必须在前，数字在后）。
- **5 列标准数据表格**：`序号`、`所在子文件夹`、`原文件名`、`逻辑父文件夹名`、`处理状态`。
- **只显示有效**：勾选后仅显示匹配成功的有效项；鼠标悬停在无效项上可查看具体失败原因。
- **规则示例弹窗**：包含专属画质增强的规则解析面板。

#### 衔接过渡与模块 2
- 模块 1 底部配备【**准备复制到[逻辑父文件夹]**】按钮。
- 若无有效图片，提示 *“抱歉，没有有效图片可以转移”* 且模块 2 维持锁定；
- 若有有效图片，解锁模块 2 并完整复用溯源分析与批量复制功能，将文件唯一定位并复制到对应的同名逻辑父文件夹。

## 🚀 快速启动

### 运行环境
- 操作系统：Windows 10 / Windows 11 (64位)
- Python 版本：3.10+

### 方式 1：一键运行 (推荐本地开发使用)
直接双击根目录下的 [`run.bat`](run.bat)：
```cmd
run.bat
```
> *若未安装环境，`run.bat` 将自动创建 `.venv` 虚拟环境并安装所需依赖后静默启动。*

### 方式 2：手动命令行运行
```bash
# 1. 创建虚拟环境并激活
python -m venv .venv
.\.venv\Scripts\activate

# 2. 安装依赖包
pip install -r requirements.txt

# 3. 运行程序
python main.py
```

## 📦 一键打包为单个独立 EXE

项目支持打包为**完全独立的单个可执行程序 (.exe)**，打包生成的文件**无需安装 Python、无需配置开发环境**，可直接发送给任意 Windows 电脑双击使用！

### 打包操作：
直接在项目根目录下双击运行 [`build.bat`](build.bat) 即可。

### 打包脚本特点：
1. **自动依赖检测**：若环境中缺少 PyInstaller，会自动联网静默安装；
2. **纯单文件封装 (`--onefile`)**：内嵌完整 Python 解释器、PySide6 驱动与动态库；
3. **视觉资源完整打包 (`--collect-all qfluentwidgets`)**：确保 Fluent 图标、字体与主题样式在脱机电脑上不丢失；
4. **无控制台黑框 (`--noconsole`)**：纯净桌面应用体验；
5. **输出结果**：生成文件位于 `dist\AiartyImageExportHelper.exe`。
